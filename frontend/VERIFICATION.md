- `npm run check:api`：校验生成类型与仓库 OpenAPI 一致。
- `npm run typecheck`：严格 TypeScript 检查。
- `npm test`：20 项测试，四个测试文件通过。

- 真实模式另做生产构建，检查可以独立打包。

测试包含：全部 37 个接口操作的请求/成功响应契约校验，错误输入、注册待验证、错误验证码与重发失效、登录/刷新/退出、私有草稿访问控制、幂等与版本头、412、429/Retry-After、404、上传/complete、READY/FAILED、PROCESSING → PUBLISHED/FAILED、修正保存、点赞收藏幂等、平层评论、资料头像和设置、改密/重置后的会话失效，以及 token/密码不落盘。

## 待真实环境验证

- 真机触屏双点按预览/打开、多指打断、低性能设备长时间拖动和实际帧率。当前已实现相应事件路径，但本次浏览器工具仅验证了窄屏与鼠标操作。

- 多个真实浏览器标签页的 refresh Cookie 轮换。客户端使用 Web Locks 协调轮换、BroadcastChannel 同步内存会话；本次自动检查证明同标签页共享刷新，未验证真实服务端的并发事务。

Mock 的本地会话标记只是一项演示状态，不是 refresh token，也不能证明真实服务端安全机制。没有为接口尚未实现的情况绕过 API 或添加共同契约之外的业务字段。
